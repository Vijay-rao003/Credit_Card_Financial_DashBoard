# Credit_Card_Financial_DashBoard
Power Bi Dashboard
presents an interactive Credit Card Financial Dashboard developed using Power BI, designed to analyze credit card transactions and customer behavior.
The dashboard provides actionable insights into revenue, transaction trends, customer demographics, card categories, and usage patterns, helping stakeholders make data-driven financial decisions.
Tools & Technologies:
Power BI – Data modeling, DAX measures, and dashboard visualization
Microsoft Excel / CSV – Data storage and preprocessing
DAX (Data Analysis Expressions) – Calculated measures and KPIs
